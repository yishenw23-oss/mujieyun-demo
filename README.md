# 牧界云 · 智慧畜牧电子围栏 Demo

> 奶牛项圈定位 + 电子围栏 + 越界告警 —— 前端交互原型

一个纯前端（HTML / CSS / JavaScript）的智慧畜牧可视化演示：在网页地图上圈定放牧区域，实时模拟奶牛定位，越界立即分级告警，并生成安全统计。

## ✨ 功能

- 🗺️ **地图可视化**：Canvas 绘制牧场地图与牛只位置
- 🖊️ **电子围栏绘制**：支持"画笔 / 矩形"两种方式圈定放牧区域
- 📍 **实时定位模拟**：奶牛（HL013 式编号）按轨迹移动，位置实时刷新
- 🚨 **分级越界告警**：接近边界 / 越出围栏，分别触发不同级别告警
- 📊 **安全统计**：越界次数、告警级别汇总展示

## 🚀 怎么运行

**双击 `demo_围栏.html`，用浏览器打开即可**（Chrome / Edge 均可），无需安装任何依赖。

## 🧠 技术点

- 原生 Canvas 2D 绘制地图与围栏
- JavaScript 事件驱动（鼠标绘制、定时器模拟移动、碰撞检测）
- 模块化告警分级逻辑，可平滑对接后端定位数据
